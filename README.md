# TinyTrails 404 Page

A responsive, animated 404-page concept for the TinyTrails brand.

## Live demo

[errorpage4o4.netlify.app](https://errorpage4o4.netlify.app)

![TinyTrails 404 preview](preview.png)

## Technology

- React and TypeScript
- Vite
- Tailwind CSS
- Lucide icons
- Netlify configuration

## Local development

```bash
git clone https://github.com/amandeavor/Error-page.git
cd Error-page
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Notes

This repository is a focused interface concept rather than a full application.
